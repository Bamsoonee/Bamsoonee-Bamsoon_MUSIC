    📋 게임 규칙

    ▼
    1️⃣ 정답 입력 규칙
    • 정답: 가수 + 제목 (예: "뉴진스 하입보이")
    • 띄어쓰기는 해도 되고 안 해도 됨 (예: "뉴진스하입보이" ✅)
    • 가수만 또는 제목만 → 오답 ❌
    2️⃣ 시간 제한
    • 정답 버튼(부저)을 누른 후 10초 이내에 입력해야 함
    • 시간 초과 → 오답 ❌
    3️⃣ 점수
    • 정답 → +1점 🎉
    • 오답 → -1점 😢
    4️⃣ 재도전 불가
    • 해당 문제에서 오답하면 재도전 기회 없음
    • 다음 문제부터 다시 도전 가능 ✨
    5️⃣ 문제 넘기기 (과반수)
    • 과반수 이상이 문제를 못 맞추면 넘길 수 있음
    • 정답이 나온 후 "다음 문제" 버튼을 눌러 진행
